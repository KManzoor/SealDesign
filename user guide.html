4. Step by Step Transaction Flow

  1. Create New Configuration
    User clicks New Seal Code from the dashboard.
  2. Select Attribute Type
    Choose one of the three output types from GP classification.
  3. Select Seal Type and Size
    Choose from the Seal Type Master and enter the size.
  4. Select Construction
    Choose Cartridge or Non Cartridge. If double seal is used, also select API Plan.
  5. Select Stationary
    Once the stationary is selected, the system auto-populates the default API Plan from the master mapping.
  6. Auto Derive Gland and Pump Codes
    Based on the selected Stationary and API Plan, the system auto-populates the Gland Type Code, and based on Pump Make plus Pump Model it auto-populates the Pump Model Code.
  7. Auto Derive Components
    The app fetches sleeve, gland, spring, O-ring and BOM items from the master tables.
  8. Preview Last Screen
    Show final generated attribute string, matched codes and BOM list.
  9. Save or Export
    Save to database or export to PDF or Excel if required.
Dependency rule for the last screen: first select Stationary to derive the Gland Type Code, then select Pump Make and Pump Model to auto-populate the Pump Model Code, and finally combine both with the MOC.

5. Final Output Rules for the Last Screen

Complete Seal = 39 - Seal Type / Seal Size - Gland Type Code + Pump Model Code + MOC Code
Complete Seal Without Gland Plate = 39 - Seal Type / Seal Size - Pump Model Code + MOC Code
Complete Seal Without Gland Plate and Without Sleeve = 39 - Seal Type / Seal Size - Stationary + MOC Code

Business Rules

  • The Pump Model Code such as A1, A2, B1 or B3 must auto-populate from the selected Pump Make and Pump Model.
  • When a stationary is selected, the API Plan must auto-populate from the stationary master.
  • When Stationary and API Plan are available, the Gland Type Code must auto-populate exactly as per the master mapping, such as G1, G11, G116 or G111.
  • The final visible code for complete seal must include both the Gland Type Code and the Pump Model Code before the MOC.
  • For complete seal, combine Gland Type Code + Pump Model Code + MOC Code in one continuous suffix.
  • MOC code must come from the GP classification master.
